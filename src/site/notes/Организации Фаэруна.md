### Умение: Ухо к Земле
Начиная с /* Применит ширину 500px к изображениям, у которых в описании есть 'width-500' */ img[alt*="width-500"] {     width: 500px;     height: auto;     display: block; }  /* Можно сделать универсальные классы */ img[alt*="width-300"] { width: 300px; height: auto; } img[alt*="width-800"] { width: 800px; height: auto; } ранга, персонаж получает умение **Ухо к Земле**:
	Вы часто контактируете с людьми из социального слоя, в котором обычно появляются цели, на которых вы специализируетесь. Эти люди могут быть связанны с криминальным сообществом, простые люди с улиц или представители высшего общества. Эта связь выражается в виде контактного лица, которое может предоставить информацию о людях и местах в любом городе и его окрестностях, которые вы посещаете.

Это умение сохраняется некоторое время даже после исключения из гильдии.

### Умение: Убежище
Будучи агентом фракции, с /* Применит ширину 500px к изображениям, у которых в описании есть 'width-500' */ img[alt*="width-500"] {     width: 500px;     height: auto;     display: block; }  /* Можно сделать универсальные классы */ img[alt*="width-300"] { width: 300px; height: auto; } img[alt*="width-800"] { width: 800px; height: auto; }-го уровня дается умение: Убежище. Вы обладаете доступом к секретной сети людей, поддерживающих вас, которые могут предложить вам помощь в ваших приключениях. Вы знаете набор секретных знаков и паролей, которые вы можете использовать, чтобы опознать таких оперативников, которые могут предоставить доступ к секретному убежищу, свободной комнате или другому ночлегу или помочь раздобыть необходимую информацию. Такие агенты никогда не подвергнут из-за вас риску собственные жизни или свою «легенду».

После выхода из фракции умение НЕ сохраняется. Однако если вы были как минимум Аспидом перед добровольным выходом из гильдии, это умение может некоторое время работать.
